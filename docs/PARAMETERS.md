# 参数手册 / Parameter Reference

`x4_case_fusion.py` 顶部 `P = dict(...)` 的逐条释义。单位全部 **mm**。
标 `(*)` 的项来自照片像素测量，**打印前请用卡尺复核**。

改参数的唯一正确流程：

```
改 P → 跑 x4_case_fusion.py → 读构建日志的 [profile] / 圆角实测 / 干涉三行
     → 跑 x4_verify.py 确认 bodies=1 → 跑 x4_render_docs.py 看图
```

## 1. 设备本体

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `dev_w` | 69.0 | 设备宽度（X） |
| `dev_h` | 114.0 | 设备高度（Y） |
| `dev_d` | 5.98 | 设备厚度（Z），同时决定内腔深度 |
| `dev_cr` | 4.0 | 设备平面圆角，只影响参考体；但**决定角部间隙的安全边界**——`inner_cr` 超过它会挤占间隙 |

## 2. 壳体通用

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `wall` | 1.8 | 背壳侧壁厚。3 道 0.4 墙线 = 1.2，1.8 留了余量给卡槽 |
| `clr` | 0.35 | 设备与内腔的单边间隙。0.25 以下难装，0.50 以上晃动 |
| `back_t` | 2.0 | 背板厚，决定底部刚性。1.6 以下捏着会弯 |
| `frame_t` | 1.2 | 前框面板厚。1.0 是下限（再薄屏幕窗口边缘会透光） |
| `outer_cr` | **3.0** | **外形平面内圆角**。方正化的核心参数，原值 6.8。改动会连带 5 处（见 §7） |
| `inner_cr` | **3.0** | 内腔平面圆角，原值 5.0。**必须 ≤ `dev_cr + 0.5`**，否则角部间隙塌陷 |

### `outer_cr` / `inner_cr` 的联合约束 ⚠️

这两个数**不能独立调**。角部壁厚和角部设备间隙都靠 720 点采样求出，
因为圆角矩形不能用"半宽差"估算角部间距。已知组合：

| `outer_cr` / `inner_cr` | 角部壁厚 | 角部间隙 | 评价 |
| --- | --- | --- | --- |
| 6.8 / 5.0 | 1.800 | **0.081** | 原设计，间隙危险 |
| **3.0 / 3.0** | **2.127** | **0.558** | **当前采用** |
| 2.5 / 2.5 | 2.162 | 0.731 | 可用，接近直角 |
| 3.5 / 3.5 | 2.098 | 0.438 | 可用 |
| 4.0 / 4.0 | 2.074 | 0.367 | 可用 |
| 4.0 / 5.0 | — | ~0.15 | 不推荐 |

安全判据：**打印日志里"角部设备间隙" ≥ 0.20 mm，角部壁厚 ≥ 1.60 mm**。

## 3. 两件套卡接

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `rebate_d` | 0.80 | 背壳前口让位深度。前口环壁厚 = `wall − rebate_d` = **1.00**。改大则环壁变薄，>1.0 会穿壁 |
| `skirt_gap` | 0.10 | 裙边内表面与让位面的径向间隙。**这是唯一的扣合"活动量"** |
| `skirt_h` | 1.20 | 裙边高度。0.8 以下扣不住，1.6 以上拆装吃力 |
| `ridge_p` | 0.35 | 裙边卡筋径向凸出量 |
| `groove_d` | 0.35 | 背壳卡槽径向深度 |
| `ridge_z0` | 5.30 | 卡筋/卡槽 Z 起点 |
| `ridge_z1` | 5.70 | 卡筋/卡槽 Z 终点（带宽 0.40） |

### 径向过盈 = 唯一的扣力公式

```
过盈 = ridge_p − skirt_gap − groove_d = 0.35 − 0.10 − 0.35 = 0.10 mm
```

| 目标 | `ridge_p` | 过盈 | 场景 |
| --- | --- | --- | --- |
| 松（常拆） | 0.30 | 0.05 | 频繁换卡 |
| **标准** | **0.35** | **0.10** | 默认 |
| 紧（长期不拆） | 0.40 | 0.15 | 单次装配 |
| 紧到极限 | 0.45 | 0.20 | 不建议，PLA 会白化 |

`ridge_z0/z1` 改动要**同时**确认仍落在前口让位区（`z0 … dev_d`）内，
且带宽 ≥ 0.30（约 2 层 @0.16）否则卡筋会退化成单层。

## 4. 屏幕窗口

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `scr_w` | 55.4 | 有效显示区宽（4.3" 480×800 ≈ 220 ppi） |
| `scr_h` | 92.4 | 有效显示区高 |
| `scr_top` | 6.5 `(*)` | 屏幕顶边到设备顶边。**决定窗口在 Y 方向的落位** |
| `win_clr` | 0.50 | 窗口单边放大量（窗口 = 显示区 + 2×0.50） |
| `win_cr` | 1.5 | 窗口圆角，随方正化从 2.5 收到 1.5 |

推导：窗口 `(scr_w + 2·win_clr) × (scr_h + 2·win_clr)` = **56.40 × 93.40**，
中心 `Yc = dev_h/2 − scr_top − scr_h/2 + ...` → 构建日志打印 `Yc=4.30`,
`上边框 6.0 / 下边框 14.6`。

`win_clr` 调到 0.25 以下时，打印收缩会导致窗口边缘压到显示区。

## 5. 正面两条胶囊按键

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `fk_yc` | 4.40 `(*)` | 按键轴线距设备底边 |
| `fk1_len` | 24.0 `(*)` | 左键长度 |
| `fk2_len` | 21.9 `(*)` | 右键长度 |
| `fk_gap` | 1.5 `(*)` | 两键净间距 |
| `fk_h` | 2.60 `(*)` | 键高 |
| `fk_clr` | 0.40 | 镂空单边放大。**同时决定两键之间竖筋宽度** |
| `fk_cr` | 1.30 | 胶囊圆角（= `fk_h / 2` 即完美胶囊） |

两键之间竖筋 = `fk_gap − 2·fk_clr` = 1.5 − 0.8 = **0.70 mm**。
`fk_clr` 超过 0.65 竖筋归零，两孔连成一条长孔。

构建日志打印实际位置：`Yc=-52.60`，左键 X `−23.70 … 0.30`，右键 `1.80 … 23.70`。

## 7. 背面

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `panel_w` | 62.6 | 装饰面板内凹区宽 |
| `panel_h` | 107.6 | 装饰面板内凹区高 |
| `panel_cr` | 1.5 | 面板圆角（方正化后 2.5 → 1.5） |
| `panel_depth` | 0.50 | 面板内凹深度 |
| `ring_od` | 60.0 | 磁吸环外径 |
| `ring_id` | 57.6 | 磁吸环内径（环宽 1.2） |
| `ring_depth` | 0.35 | 环槽深，从面板底再下切 |

## 8. 沉台与垫片

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `kb_d` | 0.60 | 按键沉台深度（让设备实键凸起时可按到底） |
| `kb_clr` | 1.00 | 沉台单边再放大量 |

| `pad_depth` | 0.40 | 垫片沉台深（贴 0.4 mm 泡棉） |

`kb_d` 调到 0.8 以上时，沉台会深到侧壁外表面那一层，外观出现可见凹坑——
