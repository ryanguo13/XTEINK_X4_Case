# 参数手册 / Parameter Reference

`x4_case_fusion.py` 顶部 `P = dict(...)` 的逐条释义。单位全部 **mm**。
标 `(*)` 的项来自照片像素测量，**打印前请用卡尺复核**。

改参数的唯一正确流程：

```
改 P → 跑 x4_case_fusion.py → 读构建日志的 [profile] / 圆角实测 / 干涉三行
     → 跑 x4_verify.py 确认 bodies=1 → 跑 x4_render_docs.py 看图
```

## 2. 壳体通用

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `wall` | **2.4** | 背壳侧壁厚。3 道 0.8 墙线；1.8 曾被嘉立创判为偏薄，且前口让位 1.2 之后环壁只剩 0.6 |
| `clr` | 0.35 | 设备与内腔的单边间隙。0.25 以下难装，0.50 以上晃动 |
| `back_t` | 2.0 | 背板厚，决定底部刚性。1.6 以下捏着会弯 |
| `frame_t` | **2.0** | 前框面板厚。1.2 时按键沉台 `kb_d = 0.6` 之下只剩 **0.59 mm** 薄壁，是嘉立创退回项之一 |
| `outer_cr` | **3.0** | **外形平面内圆角**。方正化的核心参数，原值 6.8。改动会连带 5 处（见下面的联合约束） |
| `inner_cr` | **3.0** | 内腔平面圆角，原值 5.0。**必须 ≤ `dev_cr + 0.5`**，否则角部间隙塌陷 |
| `ext_top` | **14.50** `(*)` | 上边框加长量。设备顶边到外形顶边 = `wall + clr + ext_top` = **17.25**。由 14 × 14 螺母安装面反推，见 §3.5 |
| `ext_bot` | **14.50** `(*)` | 下边框加长量，对应 17.25 mm。与 `ext_top` 同值，使外形沿 Y 对称 |

### `outer_cr` / `inner_cr` 的联合约束 ⚠️

这两个数**不能独立调**。角部壁厚和角部设备间隙都靠 720 点采样求出，
因为圆角矩形不能用"半宽差"估算角部间距。已知组合：

| `outer_cr` / `inner_cr` | 角部壁厚 | 角部间隙 | 评价 |
| --- | --- | --- | --- |
| 6.8 / 5.0 | 1.800 | **0.081** | 原设计，间隙危险 |
| **3.0 / 3.0** | **2.910** | **0.558** | **当前采用（wall = 2.4）** |
| 2.5 / 2.5 | 2.162 | 0.731 | 可用，接近直角 |
| 3.5 / 3.5 | 2.098 | 0.438 | 可用 |
| 4.0 / 4.0 | 2.074 | 0.367 | 可用 |
| 4.0 / 5.0 | — | ~0.15 | 不推荐 |

安全判据：**打印日志里"角部设备间隙" ≥ 0.20 mm，角部壁厚 ≥ 1.60 mm**。

> 表中除当前行外，其余各行是 `wall = 1.8` 时的旧测量值，仅作趋势参考；
> 角部壁厚随 `wall` 线性变化（+0.6），角部间隙不受影响。

## 3. 两件套搭接（无定位筋）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `rebate_d` | **1.20** | 背壳前口让位深度。前口环壁厚 = `wall − rebate_d` = **1.20**。改大则环壁变薄 |
| `skirt_gap` | 0.10 | 裙边内表面与让位面的径向间隙（= 唯一对中量） |
| `skirt_h` | **1.30** | 裙边高度 = `rebate_d + 0.10`，盖住 1.2 让位面再留 0.1 余量 |

### 3.1 定位筋与卡槽已整段删除

上一版在裙边上做了一圈 `ridge_p = 0.35` 的凸筋，背壳前口对应铣 0.27 深的槽，
用 +0.02 的单边间隙对中。嘉立创退回的问题正出在这里：

```
前口环壁 1.20 − 槽深 0.27 = 0.93  →  槽底圆角再吃掉约 0.2  →  0.73
槽底圆角与让位面以极浅角相切处，料厚收敛到 0  →  实测 0.10 / 0.43 两处薄壁
```

`ridge_p` / `ridge_clear` / `ridge_z0` / `ridge_z1` / `groove_d` 这一整套参数，
以及 `align_groove` 切除、`ridge_band` 拉伸，**已从脚本中删除**（不再存在）。
现在两件套靠**搭接缝**对中：背壳前口向内让位 1.20（Z 4.68…5.98），前框裙边
高 1.30 插进去，径向间隙 0.10。夹紧力全部来自 4 颗 M3 螺钉。

### 3.2 间隙的调法

- 裙边能顺利落位但四周旷动 → 把 `skirt_gap` 收到 0.08（裙边变厚 0.02）
- 裙边塞不进 → `skirt_gap` 放到 0.12，或首层流量降到 95 %
- **不要单独改 `rebate_d`**：它同时被侧壁浅凹台 `side_relief` 引用（见 §6.1），
  改一个不改另一个会立刻长出 <1 mm 的悬挑薄壁

### 3.3 前口环壁 1.20 是硬底线

`side_relief` 必须等于 `rebate_d`：侧壁孔口的浅凹台（深 `side_relief`）与背壳
前口让位面（深 `rebate_d`）若不一致，两者之间会剩一圈 0.6 宽 × 0.39 高的悬挑
台阶（实测 0.38 mm，被判薄壁）。同理，侧壁孔口上沿到让位面 `z0 = 4.68` 之间
只要还有料，就会留 0.79…0.89 的檐——所以 TF / RESET / USB-C / LED / 挂绳
五个端口都额外加了一条 `port_relief()` 凹台把它挖穿到 `z0`，见 §6.3。

### 3.4 4 × M3 螺钉与热熔螺母

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `screw_x` | 21.50 | 螺钉 X 位置（±）。受内腔半宽 34.85 限制，别超过 30 |
| `screw_y_top` | **64.35** | 上 2 颗 Y。凸台 14 高，内缘 57.35 与内腔齐平，不扎设备 |
| `screw_y_bot` | **−64.35** | 下 2 颗 Y（对称） |
| `screw_d` | 3.40 | 背壳过孔（M3 通孔） |
| `screw_head_d` | 6.20 | 沉头孔径（M3 盘头 Ø5.7 / 内六角 Ø5.5） |
| `screw_head_dp` | **1.65** | 沉头深度（M3 盘头高 1.65，压入后齐平） |
| `nut_pad_w` | **14.00** | 螺母凸台宽（X 向） |
| `nut_pad_h` | **14.00** | 螺母凸台高（Y 向）——决定孔周壁厚 |
| `nut_pad_cr` | 2.00 | 凸台平面圆角 R（背壳让位腔改为**直角**，见下） |
| `nut_pad_margin` | **0.40** | 背壳让位腔比凸台大的单边余量 |
| `nut_hole_d` | **3.60** | 螺母底孔（嘉立创 `M3*4*3` 官方口径） |
| `nut_hole_dp` | **5.00** | 底孔深（官方口径；螺母长 3.0 + 2.0 容熔料） |
| `boss_z0` | **1.00** | 凸台底面 Z（柱体朝下伸进背壳让位腔） |
| `boss_z1` | **7.98** | 凸台顶面 Z = `zf + frame_t`，与面板正面齐平 |
| `relief_floor` | **0.80** | 背壳让位腔底 Z（比柱底再低 0.20） |

**为什么是 14 × 14 平面凸台**：嘉立创代嵌有两条硬性要求——
① 螺母孔壁厚 ≥ 3 mm；② 安装面必须是 **≥ 14 × 14 的平面**（压头要有落点）。
孔 Ø3.6 时，14 × 14 让**双向**孔周壁都是 (14 − 3.6)/2 = **5.20 mm**，两条一次过。
上一版为了塞进 12.65 mm 的窄边框带，做成 12 × 10 的扁凸台，壁厚 3.05 / 4.05
只是刚过线，且不满足 14 × 14 安装面要求。

**让位腔为什么必须直角**：让位腔原本用 `nut_pad_cr + margin = R2.4` 圆角，
这道圆弧会以极浅的角度切进内腔壁（Y = ±57.35），在 16 处留下收敛到零的楔形料
（实测 0.04 / 0.06 mm）。改成 `rect_prof`（直角）后全部消失。

螺母选型：嘉立创「镶嵌螺母」下拉里的 **`M3*4*3`**，即 M3 螺纹、外径 Ø4.0、
长 3.0，官方配孔 **Ø3.6 × 深 5.0**——本项目直接采用该口径。上一版用过的
Ø3.9 × 4.0 自定义口径（"略紧抱紧"）不满足代嵌要求，已作废。列表里
`M3*6.25`(Ø6.25) 和 `M3*5.8*0.56`(Ø5.8 薄壁) 外径太大，Ø4 这一档最合适。

螺钉长度：`M3×6` 正好——沉孔底 `Z = −0.35`，螺杆 6.0 到 `Z = 5.65`，
螺母占 `1.00 … 4.00`，咬合 **3.00 mm**（满扣，详见 §3.7）。

### 3.5 上下加长量怎么来的

凸台要满足嘉立创的两条硬性要求：孔周壁厚 ≥ 3 mm、安装面 ≥ 14 × 14 平面。
落进边框带里需要：

```
凸台高 14.0 + 让位余量 0.40 + 前口让位 1.20 ≈ 17.25
```

原设计的上下边框各只有 2.15，完全放不下，所以把**壁区**加长，内腔仍是设备尺寸：

| 参数 | 默认 | 结果 |
| --- | --- | --- |
| `ext_top` | 14.50 | 设备顶边到外形顶边 2.15 → **17.25**（外形上边 74.25） |
| `ext_bot` | 14.50 | 设备底边到外形底边 2.15 → **17.25**（外形下边 −74.25） |

上下取同一个值是为了让外形沿 Y 对称（`s_cy = 0`）、4 颗螺钉的 Y 位置也对称
（上 +64.35 / 下 −64.35）。**这是能满足 14 × 14 安装面的最小对称量**：再小，
凸台就会顶进内腔。

⚠️ 改这两参数时，`panel_h`、`screw_y_top`、`screw_y_bot` 都要跟着复核。
装饰面板当前 `panel_h = 120.0`：沉孔 Y 范围 61.25…67.45，面板边在 60.0 时
距沉孔内缘还有 1.25。

### 3.6 `boss_z1` 与面板齐平

凸台顶 `boss_z1 = 7.98`，正好等于面板外表面（面板占 `5.98 … 7.98`，厚 2.0）。
凸台与面板在 Z 上完整重叠 2.0 后 `combine JOIN`，不存在零厚度接触面。
上一版是 `boss_z1 = 6.90`（比面板底面 5.98 高 0.92），凸台顶到面板外面还留
1.28 顶壁；现在面板加厚到 2.0，凸台直接做到外面，孔顶壁 1.98。

### 3.7 螺钉长度验算

```
沉孔底            Z = −0.35   (−2.00 + screw_head_dp 1.65)
M3×6 螺杆 6.0  →  端点 Z = 5.65
螺母占            Z = 1.00 … 4.00   (从底孔口压到底)
底孔顶            Z = 6.00          (boss_z0 1.00 + nut_hole_dp 5.00)

咬合 = 4.00 − 1.00 = 3.00 mm  (螺母全长，满扣)
顶部空程 = 6.00 − 5.65 = 0.35 mm  (不会顶底)
```

**为什么不用 M3×8**：端点会到 `Z = 7.65`，超过底孔顶 6.00 → 螺钉顶底，把前框
面板顶出白痕。

**为什么不用 M3×5**：咬合只剩 1.70，PLA 里反复拆装会被拉毛。

## 4. 屏幕窗口

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `scr_w` | 55.4 | 有效显示区宽（4.3" 480×800 ≈ 220 ppi） |
| `scr_h` | 92.4 | 有效显示区高 |
| `scr_top` | 6.5 `(*)` | 屏幕顶边到设备顶边。**决定窗口在 Y 方向的落位** |
| `win_clr` | 0.50 | 窗口单边放大量（窗口 = 显示区 + 2×0.50） |
| `win_cr` | 1.5 | 窗口圆角，随方正化从 2.5 收到 1.5 |

（6.5 − 0.5 / 114 − 6.5 − 92.4 + 0.5），不是外形边框。外形边框看 §3.5 的
17.25 / 17.25。

`win_clr` 调到 0.25 以下时，打印收缩会导致窗口边缘压到显示区。

### 6.3 `port_relief()`：侧壁孔口的连通凹台

所有侧壁孔口都以 `zc = D/2 = 2.99` 为 Z 中心，上沿分别在 3.79（RESET / LED）
到 4.79（挂绳）之间；而背壳前口让位面在 `z0 = 4.68`。凡孔口上沿不越过 `z0`
又没有凹台与之连通的，都会在两者之间留一圈 **0.79…0.89 的檐**（实测 0.78 / 0.89）。
USB-C / 挂绳孔口本身就贴着 `z0`，圆角相切处甚至只剩 0.02。

调 `skirt_h` 无法两全（`z0` 要抬到 5.68 才够，那样裙边只剩 0.30），所以改成
**把端口挖成与让位面连通的凹台**（电源键/翻页键原本就是这么做的）：

```python
def port_relief(yc, ylen, zlo, sign, label, pad_y=0.60):
    # 深度 side_relief(=rebate_d)，顶面恰好落在 z0，与让位面连成一片
```

五个端口（TF / RESET / USB-C / LED / 挂绳）都改成「先 `port_relief` 后 `side`」。
凹台之后剩余环壁 = `wall − side_relief` = **1.20**。其中 USB-C / LED 两处用
`pad_y=0.45`：默认 0.60 时两条凹台之间只剩 1.00（实测 0.99 mm），必须留 ≥1.2 的筋。

## 7. 背面

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `panel_w` | 62.6 | 装饰面板内凹区宽 |
| `panel_h` | **120.0** | 装饰面板内凹区高（上限 = 2 × (64.35 − 3.10 − 1.25) = 120；再大就会切进 4 个沉头孔） |
| `panel_cr` | 1.5 | 面板圆角（方正化后 2.5 → 1.5） |
| `panel_depth` | 0.50 | 面板内凹深度 |
| `ring_od` | 60.0 | 磁吸环外径 |
| `ring_id` | 57.6 | 磁吸环内径（环宽 1.2） |
| `ring_depth` | 0.35 | 环槽深，从面板底再下切 |

`ring_depth` 必须 `< back_t − panel_depth`（= 1.5），当前 0.35 非常安全。
`ring_od` 上限受 `panel_w` 限制：必须 `< panel_w`（60 < 62.6，余 1.3/边）。

⚠️ 面板与磁吸环的**圆心不是 (0, 0)**，而是 `(0, s_cy)`，当前 `s_cy = 0.00`
（上下对称加长）。若把 `ext_top` / `ext_bot` 改成不同值，`s_cy` 会偏离 0，
面板与磁吸环会整体偏移；此时要保证 `panel_h/2 < s_y1 − s_cy`。

`panel_h` 的上限由 4 个沉头孔决定：沉头 Y 范围 **61.25…67.45**，
`panel_h = 120` 时面板边在 60.00，距沉孔内缘还有 1.25；再大就会切进沉孔。

## 8. 沉台与垫片

| 参数 | 默认 | 说明 |

`kb_d` 调到 0.8 以上时，沉台会深到侧壁外表面那一层，外观出现可见凹坑——
属于设计意图，但注意 `kb_d < wall`（2.4）否则会穿壁。

`in_cr = 1.90` 与 `inner_cr = 3.0` 不同——前者是裙边内表面，后者是背壳内腔。
两者都在安全区内，不必强行对齐。

**Y 向的显式边界**：上下加长后外形不再与设备同心，所以有一整套
`s_y*` / `red_y*` / `in_y*` 显式边界（当前恰好
上下等长、`s_cy = 0`，但只要改 `ext_top` ≠ `ext_bot` 就会不对称）。
矩形特征一律用显式边界（`rrect()` 支持四边界）；只有**圆**（装饰面板、
磁吸环）用 `s_cy` 定位。`ring2_prof()` 是为两个不同心的矩形做环形轮廓而
加的——`ring_prof()` 只能同心。
