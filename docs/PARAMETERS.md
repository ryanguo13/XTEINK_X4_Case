# 参数手册 / Parameter Reference

`x4_case_fusion.py` 顶部 `P = dict(...)` 的逐条释义。单位全部 **mm**。
标 `(*)` 的项来自照片像素测量，**打印前请用卡尺复核**。

改参数的唯一正确流程：

```
改 P → 跑 x4_case_fusion.py → 读构建日志的 [profile] / 圆角实测 / 干涉三行
     → 跑 x4_verify.py 确认 bodies=1 → 跑 x4_render_docs.py 看图
```

## 2. 壳体通用

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `wall` | 1.8 | 背壳侧壁厚。3 道 0.4 墙线 = 1.2，1.8 留了余量给前口让位与定位筋槽 |
| `clr` | 0.35 | 设备与内腔的单边间隙。0.25 以下难装，0.50 以上晃动 |
| `back_t` | 2.0 | 背板厚，决定底部刚性。1.6 以下捏着会弯 |
| `frame_t` | 1.2 | 前框面板厚。1.0 是下限（再薄屏幕窗口边缘会透光） |
| `outer_cr` | **3.0** | **外形平面内圆角**。方正化的核心参数，原值 6.8。改动会连带 5 处（见下面的联合约束） |
| `inner_cr` | **3.0** | 内腔平面圆角，原值 5.0。**必须 ≤ `dev_cr + 0.5`**，否则角部间隙塌陷 |
| `ext_top` | **8.0** `(*)` | 上边框加长量。设备顶边到外形顶边 = `wall + clr + ext_top` = **10.15**。由螺钉结构反推，见 §3.5 |
| `ext_bot` | **10.0** `(*)` | 下边框加长量，对应 12.15 mm。上下不相等是因为参考照片里原设计下边框本来就比上边框宽 |

### `outer_cr` / `inner_cr` 的联合约束 ⚠️

这两个数**不能独立调**。角部壁厚和角部设备间隙都靠 720 点采样求出，
因为圆角矩形不能用"半宽差"估算角部间距。已知组合：

| `outer_cr` / `inner_cr` | 角部壁厚 | 角部间隙 | 评价 |
| --- | --- | --- | --- |
| 6.8 / 5.0 | 1.800 | **0.081** | 原设计，间隙危险 |
| **3.0 / 3.0** | **2.127** | **0.558** | **当前采用** |
| 2.5 / 2.5 | 2.162 | 0.731 | 可用，接近直角 |
| 3.5 / 3.5 | 2.098 | 0.438 | 可用 |
| 4.0 / 4.0 | 2.074 | 0.367 | 可用 |
| 4.0 / 5.0 | — | ~0.15 | 不推荐 |

安全判据：**打印日志里"角部设备间隙" ≥ 0.20 mm，角部壁厚 ≥ 1.60 mm**。

## 3. 两件套定位（无过盈）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `rebate_d` | 0.80 | 背壳前口让位深度。前口环壁厚 = `wall − rebate_d` = **1.00**。改大则环壁变薄，>1.0 会穿壁 |
| `skirt_gap` | 0.10 | 裙边内表面与让位面的径向间隙 |
| `skirt_h` | 1.20 | 裙边高度。0.8 以下定位不稳 |
| `ridge_p` | 0.35 | 裙边定位筋径向凸出量 |
| `ridge_clear` | 0.02 | 定位筋与卡槽的**单边间隙**（正数 = 有间隙） |
| `ridge_z0` | 5.30 | 定位筋/卡槽 Z 起点 |
| `ridge_z1` | 5.70 | 定位筋/卡槽 Z 终点（带宽 0.40） |

`groove_d` 不再是手填参数，而是**派生量**：`ridge_p − skirt_gap + ridge_clear`
= 0.35 − 0.10 + 0.02 = **0.27**。

### 3.1 为什么取消过盈

旧版靠 `ridge_p − skirt_gap − groove_d = 0.10 mm` 的径向过盈扣合。问题是
这个过盈完全由 FDM 的尺寸公差决定：挤出胀大 0.05 就变 0.15 紧、收缩 0.05
就变 0.05 松，同一台机器换卷料手感就变。而且拆装十几次之后卡筋会被磨圆，
扣力不可恢复地衰减。

现在夹紧力全部来自 4 颗 M3 螺钉，定位筋只做 XY 对中。**留 +0.02 的间隙**
是为了让裙边能顺畅落位，同时不至于晃动：

| `ridge_clear` | 效果 |
| --- | --- |
| −0.03 ~ 0 | 有过盈，需撬 | 
| **0.02** | **当前；落位顺，无晃动** |
| 0.05 | 手感偏松，但螺钉能补 |
| > 0.10 | 裙边会明显旷动，不建议 |

### 3.2 `groove_d` 是派生量，符号别写反

```
筋顶半径 = in_hw − ridge_p
槽底半径 = red_hw − groove_d
间隙     = (in_hw − ridge_p) − (red_hw − groove_d)
         = groove_d − ridge_p + skirt_gap
⇒ groove_d = ridge_p − skirt_gap + ridge_clear = 0.27
```

写成 `ridge_p − skirt_gap − ridge_clear`（0.23）会让槽浅 0.04 mm，筋与槽
出现 **0.02 的单边实体重叠**。Fusion 的干涉检查会报 1 处 `0.00326 cm³`，
包围盒正好是 `Z 5.30…5.70` 的整圈薄壳——STL 里肉眼看不出来。

### 3.3 间隙的调法

- 裙边能顺利落位但四周旷动 → 优先把 `skirt_gap` 收到 0.08（裙边变厚 0.02）
- 裙边塞不进 → `ridge_clear` 0.02 → 0.05，或首层流量降到 95 %
- **不要靠改 `ridge_p` 调手感**——它现在只影响筋的深度，不影响夹紧

### 3.4 4 × M3 螺钉与热熔螺母

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `screw_x` | 21.50 | 螺钉 X 位置（±）。受内腔半宽 34.85 限制，别超过 30 |
| `screw_y_top` | 61.85 | 上 2 颗 Y。上边框带 57.35…66.35 居中 |
| `screw_y_bot` | −62.85 | 下 2 颗 Y。下边框带 −68.35…−57.35 居中 |
| `screw_d` | 3.40 | 背壳过孔（M3 通孔） |
| `screw_head_d` | 6.20 | 沉头孔径（M3 盘头 Ø5.7 / 内六角 Ø5.5） |
| `screw_head_dp` | 1.80 | 沉头深度（盘头高 1.65 + 0.15 余量） |
| `boss_d` | 5.60 | 前框螺母柱外径（柱壁 = (5.60−3.80)/2 = **0.90**） |
| `boss_r_recess` | 0.30 | 背壳让位腔比柱大的单边余量 → 让位腔 Ø6.20 |
| `nut_hole_d` | 3.80 | 螺母底孔（螺母 Ø4.0，径向过盈 0.20） |
| `nut_hole_dp` | 4.20 | 底孔深（螺母长 3.0 + 1.2 容熔料） |
| `boss_z0` | 1.90 | 柱底面 Z |
| `boss_z1` | 6.90 | 柱顶面 Z（比面板底 5.98 高 0.92） |
| `relief_floor` | 1.70 | 背壳让位腔底 Z（比柱底再低 0.2） |

螺母选型：嘉立创「镶嵌螺母」下拉里的 **`M3*4*3`**，即 M3 螺纹、外径
Ø4.0、长 3.0。列表里 `M3*6.25`(Ø6.25) 和 `M3*5.8*0.56`(Ø5.8 薄壁) 外径太大，
Ø4 的螺母柱只需 Ø5.6 就不会挤占内腔。

螺钉长度：`M3×6` 正好——沉孔底 `Z = −0.20`，螺杆 6.0 到 `Z = 5.80`，
螺母占 `3.10 … 6.10`，咬合 **2.70 mm**（详见 §3.7）。

### 3.5 上下加长量怎么来的

螺母柱要从面板向下伸 4.08（`zf 5.98 − boss_z0 1.90`），加上螺母 3.0 和
沉孔 1.8，原设计的上下边框（各 2.15）完全放不下。所以把**壁区**加长，
内腔仍是设备尺寸：

| 参数 | 默认 | 结果 |
| --- | --- | --- |
| `ext_top` | 8.00 | 上边框 6.5 → **16.65**（外形上边 67.15） |
| `ext_bot` | 10.00 | 下边框 14.6 → **26.75**（外形下边 −69.15） |

`ext_top` 不能取 7.0：让位腔 Ø6.2 会顶到前口让位台阶，只剩 0.25 壁。
取 8.0 后剩 1.25。`ext_bot` 比 `ext_top` 大 2，是为了让 4 颗螺钉的 Y 位置
沿机身轴线对称分布（上 61.85 / 下 −62.85），视觉上不偏。

⚠️ 加长后**外形 Y 不再对称**：`s_cy = (s_y0 + s_y1)/2 = −1.00`。
改这两个参数时，`panel_h`、`screw_y_top`、`screw_y_bot` 都要跟着复核。

### 3.6 `boss_z1` 为什么不是 5.98

柱顶 `boss_z1 = 6.90`，比面板底面 `zf = 5.98` 高 0.92。如果只做到 5.98，
柱体与面板是**端面共面贴合**，`combine JOIN` 之后交界处只剩一条零厚度
接触环，切片布尔运算会生成非流形边。多插 0.92 让两者实体重叠。

### 3.7 螺钉长度验算

```
沉孔底            Z = −0.20   (−2.00 + screw_head_dp 1.80)
M3×6 螺杆 6.0  →  端点 Z = 5.80
螺母占            Z = 3.10 … 6.10
底孔顶            Z = 6.10    (boss_z0 1.90 + nut_hole_dp 4.20)

咬合 = 5.80 − 3.10 = 2.70 mm  (螺母长 3.0 的 90 %, ≥ 1.5×d)
顶部空程 = 6.10 − 5.80 = 0.30 mm  (不会顶底)
```

**为什么不用 M3×8**：端点会到 `Z = 7.80`，超过底孔顶 6.10 → 螺钉顶底，
结果是把前框面板顶出白痕（孔顶到外表面只剩 1.08）。要用 M3×8 必须把
`nut_hole_dp` 加到 5.2 以上，同时又会让孔顶壁薄到 0.08，不建议。

**为什么不用 M3×5**：咬合只剩 1.70，PLA 里反复拆装会被拉毛。

## 4. 屏幕窗口

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `scr_w` | 55.4 | 有效显示区宽（4.3" 480×800 ≈ 220 ppi） |
| `scr_h` | 92.4 | 有效显示区高 |
| `scr_top` | 6.5 `(*)` | 屏幕顶边到设备顶边。**决定窗口在 Y 方向的落位** |
| `win_clr` | 0.50 | 窗口单边放大量（窗口 = 显示区 + 2×0.50） |
| `win_cr` | 1.5 | 窗口圆角，随方正化从 2.5 收到 1.5 |

（6.5 − 0.5 / 114 − 6.5 − 92.4 + 0.5），不是外形边框。外形边框看 §3.5 的
10.15 / 12.15。

`win_clr` 调到 0.25 以下时，打印收缩会导致窗口边缘压到显示区。

`in_cr = 2.30` 与 `inner_cr = 3.0` 不同——前者是裙边内表面，后者是背壳内腔。
两者都在安全区内，不必强行对齐。

**Y 向不再对称**（上下加长量不同），所以有一整套 `s_y*` / `red_y*` / `in_y*` /
`tip_y*` / `groove_y*` 显式边界。矩形特征一律用显式边界（`rrect()` 支持四边界）；
只有**圆**（装饰面板圆角、磁吸环）才需要 `s_cy`。`ring2_prof()` 是为两个
不同心的矩形做环形轮廓而加的——`ring_prof()` 只能同心，加长后用不了。
