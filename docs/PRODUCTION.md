# 生产指南 / Production Guide

从 STL 到能用的外壳。以 FDM / PLA 为主，PETG 说明见 [§2.3](#23-材料选择)。

---

## 1. 打印前检查清单

- [ ] 卡尺复核 `P` 里标 `(*)` 的尺寸（屏幕顶边、按键 Y 位、USB-C 位置）
- [ ] 确认喷嘴 0.4 mm（0.2 也可，但 `skirt_h = 1.20` 的 6 层裙边会变薄）
- [ ] 首层调平到位——**背壳底面 73.3 × 118.3 mm 是大平面**，翘边会直接毁掉平面度
- [ ] 干燥耗材（PLA 开卷超过一个月建议 45 °C 烘 4 h）

---

## 2. 切片设置

### 2.1 两个文件的打印朝向

| 文件 | 朝向 | 支撑 | 说明 |
| --- | --- | --- | --- |
| `X4_back_shell.stl` | **开口朝上**，背板贴床 | **无** | 背板是 73.3×118.3 的实心平面，附着最好 |
| `X4_front_frame.stl` | **面板贴床**，裙边朝上 | **无** | 面板 1.2 mm，需良好首层 |

两件的所有悬垂都在倾角内：背壳侧壁垂直，只有内腔顶部（前口让位环的
0.8 mm 台阶）是向内的小悬挑，靠层间粘接即可；前框裙边厚仅 0.70 mm、
高 1.20 mm，切片器会自动处理。

> 如果切片器把裙边顶部的 0.70 mm 薄壁判成需要支撑，**关掉**——它一侧
> 是让位面（贴背壳），另一侧是空腔，加了支撑反而拆不干净。

### 2.2 推荐参数（PLA，0.4 喷嘴）

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 层高 | 0.16 mm（精细）/ 0.20 mm（快速） | 0.16 让 `ridge_z0/z1` 卡筋带（0.40 高）落在 2–3 层内 |
| 墙线数 | **3**（= 1.2 mm） | 侧壁 1.8 mm，3 道墙保证结构 |
| 顶/底层 | 5 / 4 层 | 背板 2.0 mm = 10 层 @0.20，足够 |
| 填充 | **25–35 %** 网格/立方 | 100 % 会让 26 g 变 26 g 且明显变脆 |
| 填充图案 | Gyroid 或 Cubic | 抗压缩各向同性 |
| 温度 | 喷嘴 210 °C / 热床 60 °C | PLA 常规 |
| 速度 | 外墙 30 mm/s，其余 60 mm/s | **外墙慢**是尺寸精度的关键 |
| 冷却 | 100 %（除首层） | 卡筋、按键镂空都靠冷却定形 |
| **水平膨胀补偿** | **−0.05 mm** | 补偿过盈，见 §2.4 |
| Z-hop | 0.4 mm | 防止搬运时喷嘴撞倒薄裙边 |
| 首层 | 0.20 mm, 25 mm/s, 110 % 挤出 | 大平面附着 |

### 2.3 材料选择

| 材料 | 优点 | 缺点 | 建议 |
| --- | --- | --- | --- |
| **PLA**（首选） | 尺寸最准，刚性好，好打印 | 60 °C 以上软化，脆，卡扣寿命短 | 桌面阅读场景够用 |
| **PLA+ / PLA-CF** | 韧性好、哑光工业质感 | CF 版磨损喷嘴 | **外观首选** |
| **PETG** | 韧性好、耐温 75 °C、卡扣不易断 | 拉丝、尺寸略肥（+0.05 膨胀） | 常开合 / 放包里 |
| **ABS/ASA** | 耐温最好 | 收缩大，卡接尺寸难控 | 不建议首版 |
| TPU | — | 无法做 0.10 mm 过盈卡接 | 只做内衬垫 |

PETG 时把 `P["ridge_p"]` 从 0.35 改 0.32（过盈 0.07），切片补偿改 −0.08 mm。

### 2.4 为什么需要 −0.05 mm 水平补偿

卡接是 **0.10 mm 径向过盈**（`ridge_p 0.35 − skirt_gap 0.10 − groove_d 0.35`）。
FDM 的实际轮廓通常比模型**外凸 0.02–0.05 mm**（挤出胀大 + 拐角堆积），
于是实际过盈会变成 0.15–0.20 mm，扣合过紧甚至扣不进。

`XY 尺寸补偿 = −0.05 mm`（PrusaSlicer: `XY Size Compensation`；
Orca/Cura: `Horizontal Expansion`）把两侧各收 0.05，正好抵掉胀大。

**调参顺序**：先打一件，试扣。
- 扣不进 → 补偿再 −0.05（总 −0.10），或 `ridge_p` 改 0.31
- 一碰就掉 → 补偿回 0，或 `ridge_p` 改 0.38

## 3. 装配

### 3.1 装设备

```
1. 设备屏幕朝上放进背壳内腔 —— 内腔 69.70 × 114.70，设备 69.00 × 114.00
   → 单边 0.35 mm 间隙，靠四个 12×12 缓冲垫沉台对中
2. 四角贴 12×12×0.4 mm 泡棉/双面胶垫（沉台正好 0.40 深）
3. 前框屏幕窗口对准设备屏幕，裙边朝背壳方向
4. 先压一个短边，听到"哒"后压另一个短边
5. 沿四周均匀压一圈，确认四周缝隙均等
```

### 3.2 拆卸

**不要用指甲从缝隙硬撬**——会掰裂 0.70 mm 的裙边。正确方法：

- 从**短边**（USB-C 那一端）的角上，用一张**废弃银行卡**（厚约 0.8 mm）
  沿着缝隙滑进去，向外小幅撬开
- 或者：从背面 MagSafe 环槽处顶住，用拇指把前框往外推

### 3.3 磁吸环

背面 φ60/φ57.6 × 0.35 深的环形槽是**让位槽**，不是磁铁腔。用法：

- 贴 MagSafe 环磁片（φ60 外径的通用环形磁片，厚 0.3–0.5 mm）
- 贴了以后设备仍能平放（磁片低于背板外表面 0.35 − 磁片厚）
- 磁片厚超过 0.35 mm 会微凸，属正常

### 3.4 挂绳

挂绳孔是 5.0 × 3.6 mm R1.2 的**通孔**，没有建模实体环。用细挂绳
（φ2–3 mm 伞绳或 2 mm 尼龙绳）穿过即可。

## 4. 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **前框扣不进** | 过盈过大 / 未做水平补偿 | 加 −0.05 补偿；或 `ridge_p` 0.35 → 0.31 重出 STL |
| **前框一碰就掉** | 过盈不足 / 材料收缩 | 补偿归 0；`ridge_p` → 0.38；PETG 换 PLA |
| **扣上后有 0.5 mm 缝隙** | 背壳/前框平面度差（翘边） | 检查首层；背壳加 brim 5 mm 重打 |
| **屏幕窗口挡到显示区** | 设备横向偏移 | 加泡棉垫对中；确认 `scr_top` 参数正确 |
| **按键按不到底** | 沉台深度不够 | `P["kb_d"]` 0.60 → 0.75 |
| **侧边开孔对不准** | 照片测量 ±1 mm 误差 | 卡尺实测后改 `P["usbc_y"]` 等，重出 STL |
| **裙边顶部拉丝/毛刺** | 薄壁冷却不足 | 降速到 20 mm/s；加 Z-hop；开"薄壁检测" |
| **磁吸环槽处表面波纹** | 0.35 mm 深槽跨 2 层 @0.20 | 层高改 0.16；或槽深改 0.40 |
| **设备装不进内腔** | XY 补偿过度（负太多） | 背壳单独打一件、补偿归 0 |
| **拆的时候裙边裂了** | 用指甲硬撬 | 按 §3.2 用卡片；PETG 重打前框 |

## 5. 后处理

1. **去毛刺**：侧边开孔（尤其 USB-C 的 9.0 × 3.4）内侧用 3 mm 圆锉轻扫一圈，
   插拔才顺
2. **RESET 孔**：φ1.6 通孔，用 1.5 mm 钻头手拧扩一下即可插针
3. **表面**：PLA 件用 400 目砂纸干磨 + 哑光清漆，能得到接近注塑的工业质感
4. **撞色**：背壳打哑光黑、前框打浅灰/米白，是最像成品的组合
5. **文字**：背板内侧可激光打标型号，不占用外观面

## 6. 质量验收

打印成品自检（对应模型的设计意图）：

| 检查项 | 标准 |
| --- | --- |
| 背壳 body 数 | 1（切片前在 Fusion 里跑 `x4_verify.py` 确认） |
| 外形尺寸 | 73.30 × 118.30 mm，公差 ±0.15 mm |
| 总厚（含前框） | 9.18 mm，公差 ±0.20 mm |
| 扣合次数 | 装拆 10 次后仍能保持扣力（PLA 建议 ≤50 次） |
| 平面度 | 背板贴平台，四周缝隙 < 0.2 mm |
| 屏幕露出 | 显示区四周均可见，无遮挡 |
| 按键 | 两条胶囊键内的设备实键可正常按下，无卡滞 |

## 8. 批量生产备注

小批量（10–100 件）建议：

- 背壳 6 件/板，间距 8 mm，加 brim 5 mm；前框 12 件/板（1.2 mm 面板可密排）
- **首件必检**：外形尺寸 + 试扣 + 屏幕窗口位置
- 卡接尺寸是唯一需要过程控制的特征 → 每 20 件抽 1 件做装拆测试
- 换卷耗材后重打首件（线径波动会直接改变过盈量）
- 若走 SLA/SLS：SLS 尼龙（PA12）尺寸最稳但表面有粉感；SLA 需选韧性树脂，
  普通树脂的卡扣会脆断
