# 生产指南 / Production Guide

从 STL 到能用的外壳。以 FDM / PLA 为主，PETG 说明见 [§2.3](#23-材料选择)。

---

## 1. 打印前检查清单

- [ ] 卡尺复核 `P` 里标 `(*)` 的尺寸（屏幕顶边、按键 Y 位、USB-C 位置）
- [ ] 确认喷嘴 0.4 mm（0.2 也可，但 `skirt_h = 1.20` 的 6 层裙边会变薄）
- [ ] 首层调平到位——**背壳底面 73.3 × 136.3 mm 是大平面**，翘边会直接毁掉平面度
- [ ] 干燥耗材（PLA 开卷超过一个月建议 45 °C 烘 4 h）
- [ ] 备好五金：**4 × M3×6 盘头螺钉** + **4 × 嘉立创 `M3*4*3` 镶嵌螺母**

## 2. 切片设置

### 2.1 两个文件的打印朝向

| 文件 | 朝向 | 支撑 | 说明 |
| --- | --- | --- | --- |
| `X4_back_shell.stl` | **开口朝上**，背板贴床 | **无** | 背板是 73.3×136.3 的实心平面，附着最好 |
| `X4_front_frame.stl` | **面板贴床**，裙边朝上 | **无** | 面板 1.2 mm，需良好首层 |

两件的所有悬垂都在倾角内：背壳侧壁垂直，只有内腔顶部（前口让位环的
0.8 mm 台阶）是向内的小悬挑，靠层间粘接即可；前框裙边厚仅 0.70 mm、
高 1.20 mm，切片器会自动处理。

**前框的 4 个螺母柱是朝下悬空的**（Ø5.6、从 Z 1.90 长到面板），
它们朝下、末端是 Ø3.8 的盲孔。切片器把它当日锥形悬垂，通常在 45–60°
之间能自支撑，**不用加支撑**；如果切片器坚持要加，只加"接触热床"
或直接忽略——加了反而会让孔口变形，螺母熔不进去。

> 如果切片器把裙边顶部的 0.70 mm 薄壁判成需要支撑，**关掉**——它一侧
> 是让位面（贴背壳），另一侧是空腔，加了支撑反而拆不干净。

### 2.2 推荐参数（PLA，0.4 喷嘴）

| 参数 | 值 | 理由 |
| --- | --- | --- |
| 层高 | 0.16 mm（精细）/ 0.20 mm（快速） | 0.16 让 `ridge_z0/z1` 卡筋带（0.40 高）落在 2–3 层内 |
| 墙线数 | **3**（= 1.2 mm） | 侧壁 1.8 mm，3 道墙保证结构 |
| 顶/底层 | 5 / 4 层 | 背板 2.0 mm = 10 层 @0.20，足够 |
| 填充 | **25–35 %** 网格/立方 | 100 % 会让 26 g 变 26 g 且明显变脆 |
| 填充图案 | Gyroid 或 Cubic | 抗压缩各向同性 |
| 温度 | 喷嘴 210 °C / 热床 60 °C | PLA 常规 |
| 速度 | 外墙 30 mm/s，其余 60 mm/s | **外墙慢**是尺寸精度的关键 |
| 冷却 | 100 %（除首层） | 卡筋、按键镂空都靠冷却定形 |
| **水平膨胀补偿** | **0 mm**（PETG −0.03） | 螺钉固定不靠过盈，见 §2.4 |
| Z-hop | 0.4 mm | 防止搬运时喷嘴撞倒薄裙边 |
| 首层 | 0.20 mm, 25 mm/s, 110 % 挤出 | 大平面附着 |

### 2.3 材料选择

| 材料 | 优点 | 缺点 | 建议 |
| --- | --- | --- | --- |
| **PLA**（首选） | 尺寸最准，刚性好，好打印 | 60 °C 以上软化，脆 | 桌面阅读场景够用 |
| **PLA+ / PLA-CF** | 韧性好、哑光工业质感 | CF 版磨损喷嘴 | **外观首选** |
| **PETG** | 韧性好、耐温 75 °C、螺母柱不易崩 | 拉丝、尺寸略肥（+0.05 膨胀） | 常开合 / 放包里 |
| **ABS/ASA** | 耐温最好 | 收缩大，螺母柱底孔会缩 | 不建议首版 |
| TPU | — | 太软，拧不紧螺钉 | 只做内衬垫 |

PETG 时唯一要动的是螺母底孔：PETG 收缩比 PLA 小但在热熔时更容易回弹，
把 `nut_hole_d` 从 3.80 收到 **3.70**，熔完冷却后螺母咬得更牢。
`ridge_clear` 保持 0.02 即可，它不影响夹紧。

### 2.4 不需要水平膨胀补偿

旧版靠 0.10 mm 径向过盈扣合，必须用 −0.05 mm 补偿抵掉 FDM 的 0.02–0.05
外凸；**现在夹紧力来自螺钉**，定位筋留的是 +0.02 mm 间隙，外凸正好把它吃掉，
反而更顺。

- 补偿设 **0**（PrusaSlicer `XY Size Compensation` / Orca、Cura `Horizontal Expansion`）
- 如果打出来裙边塞不进让位区（极少见，通常是首层过度挤出），先把
  **首层流量降到 95 %**，再考虑 −0.03
- 不要把补偿调到 −0.05：那会让前框整体缩小，4 个螺母柱与背壳让位腔错位

真正需要控的是**螺母底孔 Ø3.8**。孔小了螺母熔不进去，孔大了螺母会被
螺钉带出来。打第一件时先只打前框（45 min），熔一颗螺母试咬。

## 3. 装配

### 3.1 熔螺母（先做，别装完再熔）

四个 Ø3.8 × 4.2 的盲孔在前框内侧的螺母柱里，孔口朝下（朝背壳方向）。

```
1. 电烙铁调到 240–260 °C（PLA），装 M3 热熔螺母专用头（或平的尖头）
2. 螺母大口朝下、垂直放在孔口上，靠余热先"坐"进去 0.3 mm 对正
3. 保持垂直、轻压 5–8 s，让螺母沉到与柱底齐平（孔深 4.2，螺母长 3.0，
   沉到底会留 1.2 的容料腔 —— 不会顶到面板）
4. 撤热，压住不动 3 s 等凝固
```

- **不要用力过猛**：孔顶到面板外表面只有 1.08 mm，压穿了正面会鼓包
- 熔歪了趁热用镊子扶正；完全冷了再拧螺钉会啃坏塑料
- 熔完检查：螺母端面应与柱底面齐平或略低 0.1–0.2，不能凸出——凸出会顶住背壳让位腔底

### 3.2 装设备

```
1. 设备屏幕朝上放进背壳内腔 —— 内腔 69.70 × 114.70，设备 69.00 × 114.00
   → 单边 0.35 mm 间隙，靠四个 12×12 缓冲垫沉台对中
2. 四角贴 12×12×0.4 mm 泡棉/双面胶垫（沉台正好 0.40 深）
3. 前框屏幕窗口对准设备屏幕，裙边朝背壳方向放下
4. 四颗 M3×6 从背面对准沉孔拧入，先都拧到"刚接触"（不压紧）
5. 对角交叉逐步拧紧（左上 → 右下 → 右上 → 左下），每颗分 2–3 次到位
6. 手拧到感觉明显阻力即停 —— 约 0.2–0.3 N·m，别用电批
```

### 3.3 拆卸

拧下 4 颗螺钉即可，前框直接拿起。**不需要撬**——这是换螺钉方案最实际的收益，
定位筋只有 0.02 间隙，没有任何扣合力。拆下后螺钉建议原位插回沉孔，
免得丢失或刮花背板。

### 3.4 磁吸环

背面 φ60/φ57.6 × 0.35 深的环形槽是**让位槽**，不是磁铁腔。用法：

- 贴 MagSafe 环磁片（φ60 外径的通用环形磁片，厚 0.3–0.5 mm）
- 贴了以后设备仍能平放（磁片低于背板外表面 0.35 − 磁片厚）
- 磁片厚超过 0.35 mm 会微凸，属正常

### 3.5 挂绳

挂绳孔是 5.0 × 3.6 mm R1.2 的**通孔**，没有建模实体环。用细挂绳
（φ2–3 mm 伞绳或 2 mm 尼龙绳）穿过即可。

## 4. 常见问题排查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| **螺母熔不进去** | 底孔偏小 / 烙铁温度不够 | 钻头 3.9 手拧扩一下；温度升到 260 °C；先熔一颗试 |
| **螺母被螺钉带出来** | 底孔偏大 / 熔完没冷却就拧 | `nut_hole_d` 3.80 → 3.70 重打；熔后等 30 s |
| **正面出现鼓包/白痕** | 熔太深或拧太紧 | 孔顶离外表面仅 1.08 mm；控制烙铁下压深度；扭矩 ≤0.3 N·m |
| **前框装上去有 0.5 mm 缝隙** | 背壳/前框平面度差（翘边） | 检查首层；背壳加 brim 5 mm 重打；对角交叉拧 |
| **螺钉拧不到底（空转）** | 螺母熔歪 / 未到位 | 拆开重熔；确认螺母端面与柱底齐平 |
| **屏幕窗口挡到显示区** | 设备横向偏移 | 加泡棉垫对中；确认 `scr_top` 参数正确 |
| **按键按不到底** | 沉台深度不够 | `P["kb_d"]` 0.60 → 0.75 |
| **侧边开孔对不准** | 照片测量 ±1 mm 误差 | 卡尺实测后改 `P["usbc_y"]` 等，重出 STL |
| **裙边塞不进让位区** | 首层过度挤出 | 首层流量 95 %；`ridge_clear` 0.02 → 0.05 重出 |
| **裙边顶部拉丝/毛刺** | 薄壁冷却不足 | 降速到 20 mm/s；加 Z-hop；开"薄壁检测" |
| **螺母柱被拧裂** | PLA 太脆 / 柱壁只有 0.90 | 换 PETG 打前框；或 `boss_d` 5.60 → 6.00（让位腔自动跟随） |
| **磁吸环槽处表面波纹** | 0.35 mm 深槽跨 2 层 @0.20 | 层高改 0.16；或槽深改 0.40 |
| **设备装不进内腔** | XY 补偿给成负数 | 补偿归 0 |

## 5. 后处理

1. **去毛刺**：侧边开孔（尤其 USB-C 的 9.0 × 3.4）内侧用 3 mm 圆锉轻扫一圈，
   插拔才顺
2. **RESET 孔**：φ1.6 通孔，用 1.5 mm 钻头手拧扩一下即可插针
3. **表面**：PLA 件用 400 目砂纸干磨 + 哑光清漆，能得到接近注塑的工业质感
4. **撞色**：背壳打哑光黑、前框打浅灰/米白，是最像成品的组合
5. **文字**：背板内侧可激光打标型号，不占用外观面

## 8. 批量生产备注

小批量（10–100 件）建议：

- 背壳 5 件/板（136.3 高度比原来长 18 mm），间距 8 mm，加 brim 5 mm；
  前框 10 件/板（1.2 mm 面板可密排）
- **首件必检**：外形尺寸 + 熔螺母 + 拧螺钉 + 屏幕窗口位置
- 过程控制点在两处：**螺母底孔 Ø3.8**（用针规抽检）和**沉孔深度 1.8**
- 换卷耗材后重打首件（线径波动直接改变底孔实际直径）
- 若走 SLA/SLS：SLS 尼龙（PA12）尺寸最稳，且热熔螺母咬合最好；SLA 需选
  韧性树脂，普通树脂的螺母柱在 0.3 N·m 就会裂
- 螺钉与螺母建议随件配发（用户自己买容易买错长度：M3×8 会顶到孔底）
