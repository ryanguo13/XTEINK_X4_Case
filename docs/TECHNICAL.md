# 技术文档 / Technical Documentation

XTEINK X4 外壳的完整设计推导、几何约束、公差链与实现细节。

---

## 1. 坐标系与基准

设备在 Fusion 中的放置：

```
X = 宽  69.0 mm   +X = 正面照右手侧（电源 / 翻页 / TF 卡 / RESET）
Y = 高 114.0 mm   +Y = 顶部
Z = 厚  5.98 mm   Z=0 = 设备背面, Z=5.98 = 设备正面（屏幕面）
-X = 正面照左手侧（USB-C / LED / 挂绳孔），三者都在下端同一侧
```

所有草图以 `P3(x, y, z)` = `(mm × 0.1)` 构造——Fusion API 内部长度单位是 **cm**，
脚本里 `MM = 0.1` 负责这层换算。任何漏乘 `MM` 的地方都会得到 10 倍大小的几何。

## 3. 结构方案

### 3.1 两件套分工

```
z=-2.00 ┌──────────────────────────────┐  背板 (2.0 mm)
        │  全包背壳 X4_back_shell        │
z= 0.00 │  ↑ 设备坐在这个面上            │
        │  │ 侧壁 2.4 mm 包住设备四边    │
z= 4.68 │  └ 前口让位环（剩下 1.2 mm）    │
        │   ┌─ 裙边 1.10 mm 从外侧进入    │
z= 5.98 │   │  前框面板 2.0 mm            │
z= 7.98 └───┴──────────────────────────────┘  前框 X4_front_frame
```

- **背壳**：包裹设备背面 + 四个侧面，前口做一圈让位（`rebate_d = 1.20`），
  上下两端**对称**各加长 14.50（`ext_top = ext_bot = 14.50`），
  加长段是 **2.4 mm 壁 + 2.0 mm 背板的实心厚板**，正好容纳 4 套沉头 + 过孔。
  让位面上**没有**定位筋槽（见 3.1 下方说明）。
- **前框**：`skirt_h = 1.30` 的裙边从外侧进入背壳让位区（**无定位筋**，靠 0.10
  径向间隙对中）；裙边之上是 **2.0 mm** 厚面板，面板上开屏幕窗口和两条按键
  镂空，上下加长段的背面长出 4 个 **14 × 14 平面凸台**（Z 1.00 … 7.98，
  孔周壁厚 5.20 mm，满足嘉立创代嵌要求）。

> **0.35 定位筋已删除**。上一版在裙边上做了一圈 0.35 的筋、背壳前口对应铣
> 0.27 深的槽，结果把前口环壁（1.20）切到 0.93，槽底圆角再吃掉 0.2 → 只剩
> 0.73，圆角相切处更是收敛到 0 → 实测 0.10 / 0.43 两处薄壁，被嘉立创退回。
> 现在改由 4 颗 M3 螺钉夹紧，径向 0.10 间隙对中。

### 3.2 装配基准与公差链

**Y 向仍然对称**——加长只加在壁区，内腔仍是设备尺寸；`ext_top = ext_bot`，
所以 `s_cy = (s_y0 + s_y1)/2 = 0.00`。所有圆形特征（装饰面板、磁吸环槽）
都以 `s_cy` 为圆心，所有矩形特征改用显式上下边界 `s_y0 / s_y1`
（`rrect()` 本来就接受四个边界值，另加了 `ring2_prof()`
支持两个不同心的矩形做环形轮廓）。

| 层 | 表达式 | 值 |
| --- | --- | --- |
| 背壳外形半宽 | `hw + clr + wall` | 34.50 + 0.35 + 2.40 = **37.25** |
| 外形上边 | `tub_hh + ext_top` | 59.75 + 14.50 = **74.25** |
| 外形下边 | `-(tub_hh + ext_bot)` | −(59.75 + 14.50) = **−74.25** |
| 内腔半宽 / 半高 | `hw + clr` / `hh + clr` | **34.85 / 57.35** |
| 让位面半宽 | `tub_hw − rebate_d` | 37.25 − 1.20 = **36.05** |
| 前口环壁厚 | `wall − rebate_d` | 2.40 − 1.20 = **1.20** |
| 裙边内表面半宽 | `red_hw + skirt_gap` | 36.05 + 0.10 = **36.15** |
| 裙边厚 | 36.15 − 36.05 = | **0.10 间隙 / 1.10 实体** |
| **径向间隙** | `skirt_gap` | **0.10（唯一对中量）** |

> 旧的 `groove_d = ridge_p − skirt_gap + ridge_clear = 0.27` 推导已随定位筋（见 §3.1 引述）
> 一起删除。这个公式当年最容易写反：写反会让槽变浅 0.04、出现 0.02 单边
> 实体重叠，Fusion 会报一个整圈 0.0033 cm³ 的薄壳干涉（包围盒
> `Z 5.30..5.70`），肉眼在 STL 里完全看不出来。

### 3.3 螺钉与热熔螺母

```
        Z=-2.00 ┌──┐ 沉孔 Ø6.2 × 1.65 (M3 盘头埋入)
        Z=-0.35 │  │
                │  │ Ø3.4 过孔 (穿背板+侧壁加长段)
        Z= 0.80 ├──┤ ← 背壳让位腔底 relief_floor
                │  │ 15.4 × 14.2 直角让位腔 (空, 让凸台伸进来)
        Z= 1.00 │  │ ← 凸台底面 (前框)
                │  │ 14 × 14 凸台, 内嵌 Ø3.6 × 5.0 底孔
        Z= 6.00 ├──┤ 底孔顶 (孔深 5.0)
        Z= 5.98 │  │ ← 凸台与面板熔接
        Z= 7.98 └──┘ 前框面板外表面 (凸台顶与之齐平)
```

| 量 | 值 | 依据 |
| --- | --- | --- |
| 螺钉 | 4 × M3×6 盘头（头 Ø5.7、头高 1.65） | 头高 1.65 = 沉孔深，拧入后齐平 |
| 沉孔 | Ø6.2 × 1.65 | 比头径大 0.5，手拧不刮手 |
| 过孔 | Ø3.4 | M3 通孔标准间隙 |
| 螺母 | 嘉立创 `M3*4*3`（Ø4.0 × 长 3.0；官方孔深 5 / Ø3.6） | 下单页「镶嵌螺母」选项 |
| 螺母底孔 | **Ø3.6 × 深 5.0** | 直接采用官方口径（面板加厚到 2.0 后孔深才够） |
| 螺母凸台 | **14 × 14 平面 (R2)**，Z 1.00 … 7.98 | 孔周壁厚 (14 − 3.6)/2 = **5.20 ≥ 3.0**；安装面 ≥14×14 是嘉立创硬要求 |
| 背壳让位腔 | **15.4 × 14.2 直角** | 凸台 + `nut_pad_margin` 0.40 单边；**直角**，圆角会与内腔壁相切 |
| 凸台底到背板 | 1.00 − (−2.00) = 3.00 | 中间 0.20 是让位腔底到凸台底的空气层 |

螺钉咬合长度：`M3×6` 从沉孔底 `Z = −0.35` 起算，螺杆 6.0 → 端点在
`Z = 5.65`。螺母从孔口（Z 1.00）压入到底，占 `Z = 1.00 … 4.00`，所以
实际咬合 `4.00 − 1.00 = 3.00 mm`（螺母全长，3.0 ≈ 1.0×d，满扣）。
螺钉端点 5.65 距孔顶 6.00 还有 0.35 空程，**不会顶底**。背壳过孔段
0.80 … −0.35 只做导向，不参与咬合。

`boss_z1 = 7.98` 而不是 `5.98`（面板底面）：凸台与面板在 Z 上完整重叠
2.0 后 `combine JOIN`，否则两者只是端面贴合，交界处会留一条零厚度接触线，
切片时容易裂。凸台顶面与面板外表面**共面**（同一 `fillet_z_loop` 处理）。

### 3.4 角部圆角：这是唯一的非平凡约束

外形圆角 `outer_cr` 被 **5 处**引用（背壳主体、前口环带、卡槽环、裙边、
前框面板），内腔圆角 `inner_cr` 被 **2 处**引用，而让位圆角/裙边圆角都是
派生量：

```python
red_cr = P["outer_cr"] - P["rebate_d"]    # 让位圆角
in_cr  = red_cr + P["skirt_gap"]          # 裙边内圆角
```

方正化时把 `outer_cr` 从 6.8 直接改小是**危险的**，因为两个关键量
（角部壁厚、角部设备间隙）都不能按"半宽差"估算——圆角的曲率中心
在角部互相偏移，必须数值采样真实的最小距离。脚本内置了 `corner_metrics()`：

```python
def corner_metrics(Ro, Ri, hw, hh, clr, wall, dev_cr, n=720):
    """角部几何实测: 返回 (角部最小壁厚, 角部设备间隙)。
    圆角同尺寸矩形的角部不能用"半宽差"算, 必须采样求最小距离。"""
```

每个圆角采样 181 点（4 角 × 181），取内外轮廓点的最小成对距离。实测：

| `outer_cr` / `inner_cr` | 角部壁厚 | 角部设备间隙 | 结论 |
| --- | --- | --- | --- |
| 6.8 / 5.0（**原设计**） | 2.425 mm | **0.082 mm** | 危险：角部几乎贴死设备 |
| **3.0 / 3.0（采用）** | **2.909 mm** | **0.558 mm** | 更方正 AND 更安全 |
| 2.5 / 2.5 | 2.956 mm | 0.731 mm | 更安全但已接近直角 |
| 3.5 / 3.5 | 2.870 mm | 0.438 mm | |
| 4.0 / 4.0 | 2.836 mm | 0.367 mm | |

> 上表按当前 `wall = 2.4` 重算。旧版 `wall = 1.8` 时对应值为
> 1.800 / 2.127 / 2.162 / 2.098 / 2.074——壁厚加 0.6 后角部壁厚同步 +0.78 左右。

**关键洞察**：原设计 `inner_cr = 5.0` 比设备的 `dev_cr = 4.0` 还大，所以内腔
圆角在角部**切进了设备保留区**，间隙被压缩到 0.08 mm——这是原设计里一个
潜在的装配风险，方正化 L 反而把它修好了（间隙 → 0.56 mm）。

规律近似：`Ri ≤ dev_cr` 时间隙 ≈ `clr`（0.35）；`Ri > dev_cr` 时按约
`(Ri − dev_cr) × 0.707` 衰减。

### 3.5 断点：内腔圆角必须跟着变

`inner_cr` 若大于 `dev_cr`，角部间隙会掉到危险区。脚本在 `run()` 里打印实测值：

```
平面圆角 外 3.00 / 内 3.00 (角部壁厚 2.91, 角部设备间隙 0.56)
```

改圆角后**必须**看这行；间隙 < 0.15 mm 就该停下来重新算。

## 4. 特征清单

### 4.1 背壳 `X4_back_shell`（9 步 + 侧壁端口，13036 三角面）

| # | 特征 | 草图/范围 | 说明 |
| --- | --- | --- | --- |
| 1.1 | 外形主体 | `rrect(±tub_hw, s_y0 … s_y1, outer_cr)`，Z −2.00 … 5.98 | 一次拉伸成形 |
| 1.2 | 外底面倒圆 | `fillet_z_loop` @ z=−2.00, r=0.5 | 整圈，去手感毛刺 |
| 1.3 | 内腔 | `rrect(±cav_hw, ±cav_hh, inner_cr)`，Z 0 … 5.98 | 底板留 `back_t = 2.0` |
| 1.4 | 前口让位环 | `ring2_prof(red_hw, red_y0 … red_y1 → 外形+0.5)`，Z z0 … 5.98 | 环壁剩 `wall − rebate_d` = **1.20** |
| 1.6 | 背面装饰面板内凹 | `rr_prof(panel_cr)` 圆心 `(0, s_cy)`，自 −2.00 上切 0.50 | 62.6 × **120.0** |
| 1.7 | 磁吸环槽 | 两个 φ 圆之差，自面板底再下切 0.35 | φ60 / φ57.6，圆心 `s_cy` |
| 1.8 | 4 × 缓冲垫沉台 | `rect_prof` 12×12，深 0.40 | 中心 ±22, ±45 |
| 1.9 | 侧壁开孔 + 端口凹台 | 草图在 `yZConstructionPlane`，逐孔切穿；每个端口先 `port_relief` 铣出到前口让位面 `z0` 的浅凹台 | +X 四个 / −X 三个 |
| 1.10 | 4 × 螺钉孔 | 沉头 Ø6.2×1.65 + 过孔 Ø3.4 + 让位腔 15.4×14.2（直角） | 每处 3 刀，共 12 个特征 |

**1.10 的三个同心特征**（每处 (x, y) 相同，只是 Z 段不同）：

| 特征 | 截面 | Z 范围 | 方向 |
| --- | --- | --- | --- |
| 过孔 | Ø3.40 圆 | −2.00 … 0.80 | 自底面向上，长度 `relief_floor + back_t` = 2.80 |
| 沉头 | Ø6.20 圆 | −2.00 … −0.35 | 自底面向上的 `screw_head_dp` = 1.65 |
| 让位腔 | **15.4 × 14.2 矩形（直角）** | 5.98 … 0.80 | 自前口面向下，长度 `zf − relief_floor` = 5.18 |

让位腔尺寸 = 凸台 + 2 × `nut_pad_margin`（14×14 + 2×0.40 → 15.4×14.2），
Y 向内多挖 0.20 与内腔连通。改凸台尺寸时让位腔自动跟随。

> 让位腔必须用 `rect_prof`（直角）而不是 `rr_prof`：带 R2.4 圆角时圆角
> 会以极浅角切进内腔壁 Y = ±57.35，留下一圈收敛到零的楔形料（实测
> 0.04 / 0.06 mm × 16 处），直角化后全部消失。

**1.9 的实现细节**：`yZConstructionPlane` 的草图局部 u/v 与世界 Y/Z **不一致**，
直接用世界坐标会得到旋转 90° 的孔。`side_map(sk, wx)` 用
`sk.transform.getAsCoordinateSystem()` 把世界点投影到草图局部坐标：

```python
def pt(wy, wz):
    d = adsk.core.Vector3D.create(wx*MM - o.x, wy*MM - o.y, wz*MM - o.z)
    return adsk.core.Point3D.create(d.dotProduct(xa), d.dotProduct(ya), 0.0)
```

浅凹台（按键与端口周边的 `side_relief = 1.20`）通过 `off_plane(comp, base, z_mm)`
在 `sign × (tub_hw − depth)` 处建偏移面，只切 `depth + 3.0` 而不是切穿。

xo0 = x_cur - P["fk_clr"] - (c if i == 0 else 0.0)

## 5. 干涉检查

`analyzeInterference` 只统计**实体体积重叠**，`isCoincidentFacesIncluded = False`
（面贴合不算干涉）。三项检查全部为 0：

```
[干涉] 背壳 vs 设备              0 处  0.00000 cm3 OK
[干涉] 前框 vs 设备              0 处  0.00000 cm3 OK
[干涉] 背壳 vs 前框              0 处  0.00000 cm3 OK
```

`X4_back_shell` 与 `X4_front_frame` 在 Z 4.68 … 5.98 区间**空间上重叠**
1.30 mm——那是裙边进入让位区的设计重叠，因为两者实体本身不交叠（裙边在
让位面外侧、径向留 0.10 间隙），干涉量为 0 属预期。

> **历史教训（定位筋已删除，此坑不再存在）**：旧版定位筋槽深算错 0.04 mm
> （从 0.27 写成 0.23）就会报出 1 处 `0.00326 cm³` 的干涉，包围盒
> `X −35.62…35.62, Y −68.12…66.12, Z 5.30…5.70`——一整圈 0.02 mm 厚的薄壳，
> 肉眼在 STL 里完全看不出来。现在这类"干涉体积很小但包围盒巨大"的报警，
> 只可能来自裙边与让位面的间隙写反。

**薄壁自检**另有一个独立工具 `tools/wall_check.py`（纯标准库）：从每个三角
面片内部取 4 个采样点，沿 ±法向各打一条射线量真实料厚，跳过内切圆半径
< 0.08 的碎面与夹角 < 0.25 的掠射命中，报告所有 < 1.0 mm 的位置。当前两个
STL 的最小壁厚都是 **1.09 mm**。

## 6. 实现中踩到的坑

### 6.1 `CutFeatureOperation` 的作用域是**整个设计**，不是当前组件

这是本仓库最有价值的一条。前框 2.2 步切裙边内腔时，轮廓内表面取
`in_hw = red_hw + skirt_gap = 36.15`；这个半径**同时**也框住了背壳前口环带
（`cav_hw = 34.85 … red_hw = 36.05`，壁厚仅 1.20 mm）。于是前框的切割
从背壳环带上咬掉一条，把一个 0.0985 cm³ 的碎片从背壳主体上切了下来。

症状很隐蔽：

- 构建日志看起来全绿（体积、面积、干涉都正常）
- 只有 `X4_back_shell bodies=2` 且其中一个 `vol=0.000` 才暴露
- 碎片体积**每次运行都不一样**（0.2039 → 0.0985 cm³），因为是布尔边界的浮点残留
- STL 导出**看不出来**，因为 `biggest(comp)` 只导最大体积体

修复：`extrude()` 增加 `target` 参数，所有切割显式限定 `participantBodies`：

```python
def extrude(comp, prof, op, dist_mm, positive=True, name="", target=None):
    ...
    if target is not None and op in (CUT, JOIN, IntersectFeatureOperation):
        inp.participantBodies = _oc(target if isinstance(target, (list, tuple)) else [target])
```

然后**每一处** CUT 都要传：背壳切全部 `target=body`，前框切 `target=skirt` 或
`target=plate`。少传一处就会复发。

### 6.2 干涉输入不能给空的 ObjectCollection

```python
# ✗ 抛 RuntimeError: 3 : invalid input collections
ii = dsn.createInterferenceInput(adsk.core.ObjectCollection.create())
ic = adsk.core.ObjectCollection.create()
ic.add(body1); ic.add(body2)
ii = dsn.createInterferenceInput(ic)   # 这一步之前已经炸了
```

必须先建集合、装好实体，再传给 `createInterferenceInput`。

### 6.3 `MeshRefinementHigh` + 二进制是必须的

默认导出精度下 φ1.6 的 LED 孔会退化成寡边形。全项目 STL 体积：
背壳 652 KB（13036 三角面）、前框 375 KB（7504 三角面）。

### 6.4 其它小坑

- **`adsk.fusion.BRepBody` 没有 `bodyType` 属性**，判断用 `isSolid` / `isVisible`。
- **`Design.createInterferenceInput` 之前不能有 `analyzeInterference` 的残留状态**。
- **PowerShell 脚本里 `Add-Type -AssemblyName System.Drawing` 必须放在 `param(...)` 之后**，
  否则所有参数默认值报 `The assignment expression is not valid`。
- **WSL 侧 `urllib` 不认 `no_proxy` 里的 `127.*` 通配符**。本机有
  `http_proxy=http://127.0.0.1:7890`，于是回环 MCP 请求被送进代理并返回
  `HTTP Error 502: Bad Gateway`。`dev_run.py` 里显式建了空 ProxyHandler：

  ```python
  _opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))
  _opener.open(req)
  ```

  （`curl --noproxy '*'` 也能用，但那只是绕过了 curl 自己的代理。）

## 7. 验证方法

`x4_verify.py` 在一个已构建好的设计上跑：

1. 逐组件打印 `bodies / volume / bbox` —— **`bodies` 必须为 1**，2 即复发 6.1
   （当前基准：背壳 30.53 cm³，前框 15.49 cm³，设备参考体 46.96 cm³；
   面数随圆角/开孔细分变化，不作固定基准）
2. 三组干涉检查，必须全部 `0 处 0.0000 cm3`
3. 导出两个 STL 到 `stl/`

`x4_render_docs.py` 出 12 张白底描边图到 `docs/images/`（1600×1200，
正/背视图用 900×1400 竖版画幅，避免横版画幅在左右留大片空白）。
